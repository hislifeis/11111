# Фильтрация массива строк

## Описание
Программа фильтрует массив строк, оставляя только элементы с длиной ≤ 3 символов.

## Алгоритм
1. Получение входного массива (ввод или предустановленный)
2. Создание пустого массива-результата
3. Итерация по входному массиву:
   - Если длина текущего элемента ≤ 3, добавляем его в результат
4. Вывод отфильтрованного массива

## Примеры
- ["Hello", "2", "world", ":-)"] → ["2", ":-)"]
- ["1234", "1567", "-2", "computer science"] → ["-2"]
- ["Russia", "Denmark", "Kazan"] → []
